MLOps vs DevOps

First: DevOps

Modified, from https://www.dynatrace.com/news/blog/what-is-devops/

Development
  • Plan: Write down goals, tasks, and project rules, organize code with CCDS.
  • Code: Write the code, version control with Git.
  • Build: Package the program, build with Docker.
  • Test: Check for bugs and errors, use unit/integration tests.
Operations
  • Release: Prepare software to go live.
  • Deploy: Implement it in production, automate with Github Actions and Dagger.
  • Operate: Keep servers running, organize containers with Kubernetes.
  • Monitor: Watch system health, visualize and alert with Grafana.
And MLOps?

ML

  • Data: External info (vs internal code), version with DVC.
  • Model: Machine learning model, track with MLflow.
