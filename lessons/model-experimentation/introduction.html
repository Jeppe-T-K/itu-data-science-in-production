Notes

Exercises

The following exercises will guide you through model experimentation:

  • Exercise 0: Installation - Install MLflow and dependencies
  • Exercise 1: Run an ML Experiment - Create and log ML experiments with MLflow
  • Exercise 2: Running a Custom Model - Define and use custom models
  • Exercise 3: Check Performance of Deployed Model - Monitor for data and concept drift

Learning Goals

[!NOTE] Learning goals By the end of the exercises, we expect you to be able to do the following:

  • Organise ML experiments using common tools
  • Motivate how this can be used to deploy models
  • Explain how to detect concept and model drift

There are 4 python files in this directory for these exercises:

  • data_util.py, which you can use for generating the data (imagine it is the output of the data processing pipelines)
  • example_model.py, which you can use as the basic SKLearn model
  • basic_mlflow_training.py, which you can use to guide you on how to create a custom model/function and set up MLflow
  • basic_mlflow_evaluation.py, which you can use for evaluating the (created) models using new data and check for drifts.

As always for the most effective learning, try to use the MLflow documentation and figure out how to solve the exercises yourself first before consulting the basic MLflow scripts.
