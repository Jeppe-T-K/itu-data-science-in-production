Data Science in Production: MLOps and Software Engineering

Welcome to Data Science in Production: MLOps and Software Engineering

Welcome to the course Data Science in Production: MLOps and Software Engineering at the IT University of Copenhagen.

Course Overview

This course focuses on the practical aspects of bringing data science and machine learning models into production. You'll learn about:

  • Version control for data and models
  • Structuring MLOps projects
  • Model experimentation and tracking
  • Containerization with Docker
  • Best practices for reproducible and maintainable ML systems

Course Information

  • Course Code: BSDSPMS1KU
  • Institution: IT University of Copenhagen
  • Level: Bachelor's level

Prerequisites

Before starting this course, you should have:

  • Basic knowledge of Python programming
  • Familiarity with machine learning concepts
  • Experience with Git and version control
  • Access to a computer with administrative privileges for software installation

Learning Objectives

By the end of this course, you will be able to:

  1. Set up and maintain version control for both code and data
  2. Structure data science projects following MLOps best practices
  3. Track and manage ML experiments using industry-standard tools
  4. Containerize ML applications for reproducibility
  5. Collaborate effectively on data science projects
  6. Monitor model performance in production

Course Structure

The course is organized into the following lessons:

  1. Introduction - Course overview and prerequisites
  2. Data and Model Versioning - Using DVC for data and model tracking
  3. MLOps Projects Overview - Structuring projects with Cookiecutter Data Science
  4. Model Experimentation - Experiment tracking with MLflow
  5. Containers and Docker - Containerizing ML applications

Slides

Slides for each week are available on LearnIT.

Getting Started

To get started with the course:

  1. Review the prerequisites and ensure you have the necessary tools installed
  2. Familiarize yourself with the course structure and lesson plan
  3. Begin with the first lesson on Data and Model Versioning
